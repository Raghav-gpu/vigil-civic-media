# InViGiL / AP Media Landing Page

## Goal
Create a responsive, dark cinematic landing page for InViGiL by AP Media that presents the platform’s verified journalism, investigations, ViERA AI tools, publishing ecosystem, audiences, trust model, and pricing.

## Build
- Establish the supplied navy, violet, cyan, blue, and breaking-red brand system with Space Grotesk, Geist-style body typography, controlled glow, and accessible contrast.
- Build a prominent first screen with the InViGiL wordmark, AP Media identity, ViERA badge, positioning copy, three calls to action, and an original product-interface composition.
- Add concise sections for the core platform pillars, target audiences, INVIGIL workflow, trust and safety, plans, and the wider media ecosystem.
- Use the uploaded wing mark as visual reference only; recreate a compatible abstract brand treatment without embedding the source photo.
- Add polished navigation, mobile menu behavior, audience tabs, clear live/coming-soon labels, and a complete footer.
- Add page-specific search and social metadata.

## Technical details
- Keep the experience on the existing home route and use the project’s TanStack Router architecture.
- Use the existing button and tabs controls for interactions.
- Define all visual colors, typography, shadows, and motion as semantic design tokens in the global stylesheet.
- Keep animations subtle and disable them when reduced motion is preferred.
- Verify the rendered page at desktop and mobile sizes, including interaction and overflow checks.
